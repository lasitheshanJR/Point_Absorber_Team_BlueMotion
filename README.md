# Point_Absorber_Team_BlueMotion
The Team BlueMotion project is focused on the development of a point absorber wave energy converter (WEC) system designed to generate electricity from ocean waves and store the captured energy in a battery bank. The system incorporates a monitoring and alert model that detects and signals hazardous operational conditions.
